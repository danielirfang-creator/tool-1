# CraftCalc — DIY & Home Improvement Calculator Hub

CraftCalc is a production-ready, SEO-first, AdSense-ready calculator platform built for homeowners, DIY enthusiasts, and trade professionals.

## 🚀 Features
- **33 Launch Calculators** across 6 topical clusters (Flooring, Painting, Concrete & Masonry, Garden & Outdoors, Rooms & Walls, Conversions).
- **Flagship Flooring Suite** with interactive live calculations, dynamic waste factors (5% to 20%), box rounding, thinset mortar, grout, and underlayment estimates.
- **Strict 6-Section SEO Architecture** per tool page for maximum search visibility and high-intent topical authority.
- **100% Client-Side Calculations**: Zero server database overhead, fast Core Web Vitals, and total user privacy.
- **Zero-CLS AdSense Containers**: Pre-allocated ad slots with clear labels and interactive cookie consent banner.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (SSG / Static Site Generation)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React
- **Deployment**: Vercel / Netlify
